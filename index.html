01 / The difference

Not smoother.
More intentional.

Tradimation treats motion as a sequence of readable drawings connected by uninterrupted force—not a start value slowly becoming an end value.

01 / POSE

Draw the extremes

Keep the original

02 / Framework agnostic

One element.
One line to play.

Use the registry directly from JavaScript, or wrap the same controller lifecycle in the framework of your choice.

Quick start01 / Select02 / Play03 / Control
import { playEffect } from '@tradimation/core';

const button = document.querySelector('.checkout');

// Same API in vanilla JS, React, Vue, Svelte, or anywhere else.
const motion = playEffect(button, 'smear', {
  duration: 700,
  cleanup: 'restore'
});

motion.finished.then(() => motion.destroy());
