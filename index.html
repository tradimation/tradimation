Use it directly

The application owns state and lifecycle. Tradimation returns a controller for the visual effect.

import { playEffect } from "@tradimation/core";

const controller = playEffect(button, "anticipation-take", {
  direction: "right",
  intensity: 0.9
});

button.addEventListener("pointerleave", () => controller.reverse());
